## An Spring Boot based application with base interfaces

This project is a template project that provide a fast adoption of Spring Boot enterprise features and quick ePaaS ready application creation.

### Out-of-box Features:

#### REST API support

- Services Interfaces with Traditional or Reactive (Flux and Mono) styles
- IdentifiableOrderedDto may be used as root parent class for all DTO

<br/><br/>

---

### Usage

```
  <dependencies>
    <dependency>
      <groupId>org.springpr.springpr</groupId>
      <artifactId>springpr-rest-interface-template</artifactId>
      <version>${springpr-rest-interface-template.version}</version>
    </dependency>
  </dependencies>

```
