#### Eclipse Installation

If we're using Eclipse IDE, we need to get the Lombok jar first. The latest version is located on Maven Central. For our example, we're using lombok-1.18.26.jar.

Next, we can run the jar command via

```
java -jar lombok-1.18.26.jar
```

an installer UI will open. This tries to automatically detect all available Eclipse installations, but it's also possible to specify the location manually.

Once we've selected the installations, then press the Install/Update button.
